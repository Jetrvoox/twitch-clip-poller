Privacy Policy

Last updated: 2026-08-07

"Darwin Project Clipping" is a personal, non-commercial project run by a single operator. It is not offered to the public and does not collect data from third-party users.

What data this app handles

  • Public Twitch clip metadata — clip ID, broadcaster name, title, view count, URL, thumbnail, creation date. All of this is already public on Twitch.
  • Operator's own TikTok account credentials (via TikTok's OAuth flow) — used solely to post approved clips to the operator's own TikTok account.
  • Operator's own Discord account — used for the manual clip-approval step.

No data is collected from, or about, any third party / end user. This app has no public-facing users other than its single operator.

Data storage

All data is stored locally on the operator's own machine (a local SQLite database). Nothing is shared with, sold to, or accessible by any third party.

Data retention

Data is retained for as long as the project is in use, at the operator's discretion, and can be deleted at any time by deleting the local database.
